# Lớp tích hợp giao diện

- `renderer.mjs`: hoạt ảnh tạm thời, nền tĩnh, nút cài đặt và khôi phục.
- `payload.mjs`: đóng gói HTML, CSS, ảnh và mã từ máy.
- `cdp.mjs`: chọn cửa sổ chính, xác minh WebSocket nội bộ và xử lý thời gian chờ.
- `run.mjs`: launcher macOS gốc.
- `wallpaper.css`: làm trong suốt các bề mặt để hiện nền.
- `../tools/windows-launch.ps1` và `../tools/windows-inject.mjs`: launcher và bộ nạp Windows.

Giữ nguyên gói ứng dụng chính thức. Thoát hoàn toàn ứng dụng để đóng cổng gỡ lỗi. Xem [hướng dẫn tiếng Việt](../WINDOWS.md).
